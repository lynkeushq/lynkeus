# +system in the header: a view the app did not draw

A system alert or a native SDK's sheet is in front. When it runs in the app's process its words are listed (`~system`): press its button by text, or add it to `cases.interruptions`. When another process draws it (iOS's "Save Password?"), nothing in the app can tap it: sign in through an app command (`qa.register`) so the suite never meets it. A case that starts under such a view is relaunched before its first step. React Native's "Refreshing..." banner is not one (an app built with an older agent still lists it): frames wait for it to go.
