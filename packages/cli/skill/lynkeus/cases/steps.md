# Steps: every app.* step and its arguments

`app.press`, `app.type` (`{ text, target?, submit?, clear? }`), `app.swipe`, `app.wait` (route, target, ms, `{ target, scroll: true }` (returns once the scrolled list has stopped, so the next press finds the target there), `{ anyOf: [...] }`, `{ request: "GET /path", status? }`), `app.see` (`{ testId?, text?, contains?, route?, request? (answered, unless `answered: false`), event?, absent? }`), `app.nav` (a teleport to where the case starts; a screen in a nested navigator can be named alone; right after a sign-in that swaps the navigator's screens it waits for one that declares the route, and fails if none does), `app.back`, `app.relaunch`, `app.call`, `app.mock`, and any other Lynkeus command as `app.<command>` with its arguments by name. A step that is not `app.*`, `exec` or `assert` is a fixture: see the cases README.
