# app.relaunch: start the app fresh

Starts the app again as a fresh case finds it: terminated and launched on a Simulator or emulator, a host the run started is started again, any other host mounts the app again. The case's mocks go with it; set them after. A case that starts under a view the app did not draw (a system prompt the case before left) is relaunched before its first step, and its result says so.
