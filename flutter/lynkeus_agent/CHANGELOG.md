## 0.7.5

- First release on pub.dev. The in-app agent for Flutter apps: `LynkeusAgent.start()` in a debug build, the widget tree, touches, text input, routes (`LynkeusNavigatorObserver`, `LynkeusRoutes`) and `dart:io` requests for Lynkeus's `requests`, `trace` and `mock`. It shares its version with the `lynkeus` npm packages.
